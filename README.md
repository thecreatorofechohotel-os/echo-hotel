# echo-hotel

Welcome to Echo Hotel — a little 3D hotel island where Echo lives.

## How to play

* **WASD / Arrow Keys** — Move
* **E** — Interact
* **Mouse drag** — Move the camera
* **Mouse wheel** — Zoom

## Secret Island

There is a small private island in the top-right area of the map.

The passcode is:

**ECHO**

## About

Echo Hotel is a free 3D web prototype designed to be embedded into a Google Site.

The hotel currently includes:

* A 3D island
* Echo Hotel
* Swimming pool
* Food area
* Hotdog stand
* Dock and boat
* Trees and beaches
* Echo wandering around
* A secret island
* A locked gate
* A mysterious cabin

More features will be added later.
